# 리눅스 260414 8장 프로세스

## 프로세스 관련
### 전면 처리, 후면 처리
- 전면 처리 : 끝날때까지 실행. 앞(前面)에서 처리하니까?
- 후면 처리 : 알아서 실행하고 다른거 가능. 뒤(後面)에서 몰래 처리하니까?

`sleep 100`


`sleep 5; ls`

sleep 5 실행 후에 (5초 동안 대기) ls 실행

```
$ sleep 100
$ (sleep 100)&
```

기본적인 실행은 전면 처리, &를 사용하는 건 후면 처리라고 보면 됨
작업자는 할거하고 os가 알아서 프로세스 처리함


대강 이런 식으로 

[코드 링크](./08/wait.c)
```c
//./08/wait.c
#include <unistd.h>
#include <stdio.h>
int main(int argc, char** argv) {
    if(argc<2) { perror("Shut up"); return 1;}
    // sleep num (sec)
    int num = atoi(argv[1]);
    printf("sleep : %d\n",num);
    sleep(num);
    puts("end");
    return 0;
}
```
```
$ gcc wait.c -o wait
$ ./wait 2
sleep : 2
end
$ ./wait 200 &
[1] 3933
sleep : 200
```

### fg
`fg [번호]`
```
$ fg 1
./wait 200
end
$
```
fg를 사용해서 
jobs -l 에서 [1]+ 에서 후면 처리하는 프로세스를 전면으로 바꾸고 싶으면
`fg 1`를 입력. 

`Ctrl+C`(^C)를 하면 종료됨
