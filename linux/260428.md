## fork
자료는 C언어면서 과제는 왜 파이썬임?
- `os.getpid`
- `os.fork`
```py
os.getpid
pid=os.fork()

```
```c
#include <unistd.h>
#include <sys/types.h>
int main() {
getpid();
int pid=fork();

#if pid == 0 -> child process
#else -> parent process
if(pid==0) printf("Child pid=%d", getpid());
else printf("Parent pid=%d", getpid());

return 0;
}
```

### fork example
```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int main() 
{
  int pid1, pid2;
  pid1 = fork();
  if (pid1 == 0) {
    printf("[Child 1] : Hello, world ! pid=%d\n",getpid());
    exit(0);
  }
  pid2 = fork();
  if (pid2 == 0) {
    printf("[Child 2] : Hello, world ! pid=%d\n",getpid());
    exit(0);
  }
  printf("[PARENT] : Hello, world ! pid=%d\n",getpid());
}

```
